# Intent: AI-Enabled Profile Site

## Purpose
A personal portfolio website featuring a grounded chatbot that answers recruiter and prospective collaborator queries based strictly on my profile data, refusing to fabricate expertise.

## Target Audience
Recruiters, hiring managers, and prospective project collaborators.

## Core Commitments
1. The chatbot will answer strictly using facts provided in the profile schema.
2. Unshipped or unearned skills will be explicitly flagged or referred to the Not Yet inventory.
3. No API keys or credentials will be committed to the repository.
